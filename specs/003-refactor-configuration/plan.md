# Implementation Plan: Refactor Configuration to Dedicated Classes

**Branch**: `003-refactor-configuration` | **Date**: 2026-09-11 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/003-refactor-configuration/spec.md`

## Summary

Extract all bean declarations and infrastructure annotations from the root `@SpringBootApplication` entrypoint classes across all 8 microservices and gateway into dedicated `@Configuration(proxyBeanMethods = false)` classes within each service's `config` package (`nl.invokedynamic.demo.<service>.config`). This ensures clean separation between application bootstrapping orchestration and component infrastructure wiring.

---

**Language/Version**: Java 26 (Preview / Early-Access)

**Storage**: PostgreSQL 17 (schema validation/Flyway), Redis 7 (caching)

**Target Platform**: Linux / macOS containerized microservices running via Docker Compose  
**Project Type**: Multi-module Maven reactor backend microservices platform  
**Performance Goals**: Fast startup time; zero CGLIB proxy overhead via `proxyBeanMethods = false`  
**Constraints**: Zero changes to external API/event contracts; 100% test pass rate across all 10 modules  
**Scale/Scope**: 8 microservices + 1 gateway (customer, restaurant, reservation, availability, waiting-list, notification, analytics, gateway)
