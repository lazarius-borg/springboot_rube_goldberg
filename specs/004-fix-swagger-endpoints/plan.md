# Implementation Plan: Public Access to OpenAPI and Swagger UI Endpoints

**Branch**: `004-fix-swagger-endpoints` | **Date**: 2026-09-13 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/004-fix-swagger-endpoints/spec.md`

## Summary

Resolve HTTP 401 Unauthorized responses when accessing Swagger UI (`/swagger-ui.html`, `/swagger-ui/**`) and OpenAPI schema endpoints (`/v3/api-docs/**`) on microservices configuring Spring Security (`customer-service`, `restaurant-service`, `reservation-service`, `availability-service`, `waiting-list-service`). Define dedicated `SecurityConfig` and `OpenApiConfig` classes in each service's `config` package, permitting unauthenticated documentation exploration while strictly enforcing OAuth2 Resource Server JWT authentication on all business routes and actuator paths. Enable the global Swagger UI "Authorize" dialog by declaring an HTTP Bearer JWT security scheme in OpenAPI definitions, and update the project README with clear walkthrough instructions.

## Implementation Strategy

### Phase 1: Security Configuration in Domain Services (User Story 1 & 2 - P1 & P2)
1. Implement `SecurityConfig` in `nl.invokedynamic.demo.<service>.config` across all 5 secured services (`customer`, `restaurant`, `reservation`, `availability`, `waiting-list`).
2. Configure `SecurityFilterChain` permitting `/swagger-ui.html`, `/swagger-ui/**`, and `/v3/api-docs/**`, while enforcing `.anyRequest().authenticated()` with OAuth2 Resource Server JWT validation.
3. Add security slice/integration tests in each service verifying HTTP 200 on Swagger endpoints and HTTP 401 on protected endpoints.

### Phase 2: OpenAPI Bearer Auth Configuration (User Story 3 - P3)
1. Extract `@OpenAPIDefinition` from `*Application.java` into dedicated `OpenApiConfig` classes across `customer`, `restaurant`, `reservation`, `availability`, `waiting-list`, and `analytics`.
2. Add `@SecurityScheme` (`bearerAuth`) and `@SecurityRequirement(name = "bearerAuth")` to display the "Authorize" button in Swagger UI.

### Phase 3: Documentation & Verification
1. Update `README.md` under "How to Use Swagger UI for Manual Inspection" explaining unauthenticated documentation exploration and token usage for "Try it out".
2. Run full Maven reactor test suite (`./mvnw clean test`) and execute quickstart validation scenarios.
